Generated by SkinLutGenerator.referenceProfile(): 256 x 128 RGB16F, maximum curvature 1/mm,
128-point Gauss-Legendre ring integration per Gaussian. No gamma or tone mapping.
X = NdotL * .5 + .5; Y = sqrt(curvature / maximumCurvature).
Domain endpoints are texel centers. Use bilinear clamp sampling without mipmaps or Y flip.
ReferenceLut.j3o contains an Image for TextureKey, not a Texture2D or scene model.

Regenerate by generating the same Result and exporting result.createTexture().getImage()
with BinaryExporter. SkinLutGeneratorTest verifies the shipped data against CPU generation.
The SDK Tools / Textures / Pre-integrated Skin Tools exports custom LUTs and materials.

The reference Gaussian fit follows d'Eon et al., Efficient Rendering of Human Skin (2007),
and GPU Gems 3 chapter 14. That chapter describes the fit as a Caucasian-skin starting point,
not a measurement of every person in a population. Other supplied presets are artistic
distance adjustments. Skin pigmentation still belongs in the material albedo.
Normal prefiltering uses the same Profile with explicit texel density; it does not generate curvature.
